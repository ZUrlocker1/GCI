# Xcode Project Setup Guide

The Xcode `.xcodeproj` file is not stored in the repository (it is generated by Xcode and contains machine-specific paths). Follow these steps to create it fresh.

## 1. Create the Xcode Project

1. Open Xcode → **File → New → Project**
2. Choose **macOS → Game**
3. Settings:
   - **Product Name:** `GalacticChessInvaders`
   - **Team:** your Apple ID / developer account
   - **Organization Identifier:** `com.yourname.gci` (or similar)
   - **Game Technology:** SpriteKit
   - **Language:** Swift
   - **Include Tests:** ✅ Yes
4. **Save location:** `/Users/urlocker/Downloads/GCI/` — Xcode will create a `GalacticChessInvaders.xcodeproj` here

## 2. Replace the Default Source Files

Xcode creates a default `GameScene.swift` and `Actions.sks`. Delete these and use the source files from `GalacticChessInvaders/`:

- Delete Xcode's generated `GameScene.swift`, `GameViewController.swift`, `AppDelegate.swift`
- Add all files from `GalacticChessInvaders/` to the project target:
  - Right-click the project in navigator → **Add Files to "GalacticChessInvaders"**
  - Select the `GalacticChessInvaders/` folder, check **Create groups**, add to target

## 3. Add the Sprite Atlas

1. In Xcode's project navigator, find your asset catalogue (`Assets.xcassets`)
2. Drag `assets/GCI.spriteatlas/` into `Assets.xcassets` in Xcode
3. Xcode will recognise it as a sprite atlas automatically

## 4. Add Music Files

1. In Xcode, create a group called `Music` inside the project
2. Drag your `.m4a` files from `assets/music/` into this group
3. Ensure **Add to target** is checked for each file

## 5. Add ChessKit via Swift Package Manager

1. **File → Add Package Dependencies**
2. Enter: `https://github.com/aperechnev/ChessKit`
3. Version rule: **Up to Next Major** from `2.0.0`
4. Add to the `GalacticChessInvaders` target

## 6. Add Press Start 2P Font

1. Download **Press Start 2P** from Google Fonts: https://fonts.google.com/specimen/Press+Start+2P
2. Add `PressStart2P-Regular.ttf` to the Xcode project (drag into project navigator, add to target)
3. In `Info.plist`, add key `Fonts provided by application` (array) with value `PressStart2P-Regular.ttf`

## 7. Configure the Window (macOS)

In `Info.plist` or via the project settings:
- Set initial window size to **960×700** points
- Set minimum window size to **640×500** points
- Do NOT set `LSUIElement` (app should appear in Dock)
- Do NOT use `NSFullSizeContentViewWindowMask` — the game runs in a standard window

## 8. Configure Build Settings

Recommended settings:
- **Swift Language Version:** Swift 6
- **Deployment Target:** macOS 14.0 (Sonoma)
- **Debug:** assertions on, diagnostics panel visible
- **Release:** optimisation level `-O`, strip debug symbols

## 9. First Build Check

After setup, build (⌘B) and run (⌘R). You should see:
- A black window (960×700)
- Twinkling starfield (once Phase 0 is implemented)
- No crashes or missing resource warnings
- Diagnostics sidebar with "STARTUP — GalacticChessInvaders initialised"

## 10. Open in VS Code / Claude Code

```bash
cd /Users/urlocker/Downloads/GCI
code .
```

Claude Code will read `CLAUDE.md` automatically on session start and have full project context.

Format

Transparent PNG, 32-bit alpha, packed in an Asset-Catalog .spriteatlas. One file per frame.

Scaling

Authored at native @1× (sizes above). Upscale at runtime with texture.filteringMode = .nearest for crisp pixels.

Glow

Applied live via SKEffectNode + Gaussian blur, additive. Never baked into the PNG.
